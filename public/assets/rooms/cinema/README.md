# Video Loop Drop-In Directory — Cinema & TV Hub (`public/assets/rooms/cinema/`)

Place silent H.264 `.mp4` (or `.webm`) seamless loop video files here using these exact filenames:

1. `movie.mp4` — فیلم سینمایی (سالن نوآر کلاسیک)
2. `series.mp4` — سریال (اتاق مانیتورینگ جنایی)
3. `anime.mp4` — انیمه (کوچه توکیو در باران)
4. `documentary.mp4` — مستند (کمپ کوهستانی در مه)
5. `tv-climax.mp4` — تلویزیون و کلایمکس (استودیوی رترو دهه ۸۰)

While any file is missing, `SpatialVideoEnvironment` renders an animated Unreal 5.8 spatial fallback without crashing.
